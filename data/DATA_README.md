# Data notes
All files in this folder are SYNTHETIC and generated by `generate_synthetic.py` (seed 42).
- `cutoffs.csv`: closing rank per college / course / quota / category / year (2023-2025).
- `seat_matrix.csv`: seats per college / course / quota (2025).
- `counselling_faq.md`: illustrative process text written for this demo; not official rules.
No real student, doctor or client data is used. No external dataset or licence applies.
College names are invented; any resemblance to real institutions is coincidental.
